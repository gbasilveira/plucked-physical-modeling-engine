## Review checklist

**Scope and independence (blocking if violated)**

1. Commits touch only `reference/**`, `tools/reference-cli/**`, `tools/tests/test_p0_5_ribs_*.py` and docs/dev/reference-solver.md. No workflow, CMake preset, dependency or `engine/include` change.
2. No code, constant or test value comes from B2 (`git grep` the reference for `pme_compiler`, `skfem`, `scipy`, `gmsh`); no third-party eigen-solver; the Jacobi and subspace iteration are the reference's own.
3. Every existing reference function and Python binding behaves as before; with no ribs the plate path is bit-identical (compare a P0.5-T4 run before and after on the same build).

**Physics and numerics (blocking if wrong)**

4. Rib model: E I = E·width·height³/12, ρA = ρ·width·height, beam at z = 0, no torsion, rotary inertia or offset, all stated in the module note and README.
5. Stiffness: 3-point second difference along the rib's grid line with weight h\_s on interior line nodes; edge nodes w = 0; assembled symmetric. Mass: lumped ρA·h\_s, half at the two rib ends. Check by hand for a 3-node rib.
6. Lévy reference (test 6): re-derive the jump condition D₁₁[X'''] = −(E I β⁴ − ρA ω²) X(x₀) yourself and confirm the code's sign; confirm the root bracketing finds every root in the range (no skipped roots: compare the count with the unribbed plate's modes for that n). Recompute two of its frequencies yourself in a scratch script (any language, your own derivation).
7. Modal solve: deterministic start block; Rayleigh–Ritz; stopping rule 10⁻¹³ relative on the `count` lowest Ritz values; residual check ≤ 10⁻⁹; failure is a `RefError`, never a silent result. Scratch check: for one small ribbed grid (for example 12 × 8), assemble K and M densely from the reference's own operator output, solve with any dense eigen-solver in scratch, and compare the 20 lowest values within 10⁻¹⁰.
8. Validation: diagonal ribs, z ≠ 0, ends outside the plate, off-grid lines and non-positive section or material are rejected with `ribs[i]` named; every other plate limit is still rejected.

**Tests and CI**

9. Tests 1 to 9 exist under the brief's names and pass in `linux-debug` and `linux-release` with GCC and Clang; test 5's observed orders and test 6's errors are in the report and plausible (second order; Lévy within 0.1%); the energy test includes crossing ribs.
10. The Python test skips without the module and fails on a skip under `PME_REFERENCE_REQUIRED=1`; the CLI subcommand matches the binding.

**Quality**

11. clang-format, clang-tidy, ruff and mypy clean; docs/dev/reference-solver.md covers the rib model, discretisation, modal solve, the Lévy derivation and how B2-T4 should call `plate_modes`.
